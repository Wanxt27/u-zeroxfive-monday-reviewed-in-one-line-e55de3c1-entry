A make.fun entry for [Monday, Reviewed in One Line](https://make.fun/bounty/u-zeroxfive-monday-reviewed-in-one-line-e55de3c1).

`main.ts` (Node 22, stdlib only) writes exactly one line — 161 characters — to `/output/entry.txt`:

> My Monday opened with 47 unread emails, a 9 a.m. meeting about meetings, and a coffee that filed for resignation before I did — one star, would not Monday again.

The inbox count and the 9 a.m. meeting about meetings are the concrete Monday; the coffee quitting before the reviewer does is the turn, and the one-star verdict is the line a coworker repeats the next morning. Plain voice, no wasted words.

Run it with:

```sh
node main.ts
```
